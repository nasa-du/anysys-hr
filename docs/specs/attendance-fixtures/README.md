# 考勤导入 Fixtures

本目录是「打卡与 OA 申请导入管线定稿」的样例导入文件，供导入解析测试与「考勤计算规则、日结果与月汇总定稿」的黄金用例直接引用。

- 编码：UTF-8（无 BOM）
- 分隔符：逗号
- 表头：保留钉钉 / OA 导出的原始列名；未映射的列应被忽略
- 目标月份：除特别说明外均为 `2026-09`

## 6. 跨月导入说明

- 打卡第 11 行、出差第 7 行、加班第 10 行、请假第 3 行都涉及跨月归属。
- 9 月批次只保存与 9 月相关的部分：打卡按考勤日期、出差按起止范围、加班按目标月内的按日分钟、请假按休息范围或上班开始/结束日期。
- 10 月批次应使用同一份导出再次导入，以验证「每月独立快照 + 覆盖式刷新」。
