# 基础管理 · 交互原型

低成本 HTML 原型，用于讨论基础管理的信息架构与关键交互。**不是生产代码**；数据保存在内存中，刷新即重置。

> 已确认（2026-11-01）：基础管理前端采用 **方案 A · 五模块独立**。方案 B / C 保留在原型中作为备选参考，不进入实施方案。

## 打开

直接双击 `index.html`，或用任意静态文件服务器打开。无需安装依赖。

- 默认方案 A。
- 底部悬浮条切换方案；键盘 `←` / `→` 也可切换（输入框内不拦截）。
- 「页面流程」查看当前方案的页面流程图。
- 「需求差异」查看与需求文档的差异。
- 「深色 / 浅色」切换主题；也可以用 `?theme=dark` 直接打开深色。
- 「状态」切换正常 / 加载中 / 空数据 / 错误，检查列表与详情状态。
- 「重置」恢复初始数据。

## 三个方案

| 方案 | 导航 | 公司上下文 | 员工页 | 部门 / 岗位 | 成本中心 |
|---|---|---|---|---|---|
| **A 五模块独立** | 侧边栏五个独立入口 | 顶栏全局切换器 | 左侧部门树 + 全宽表格 + 右侧表单抽屉 | 部门树 + 右详情；岗位全宽列表 | 左树 + 右详情 |
| **B 组织工作台** | 侧边栏单入口 | 工作台顶部选择器 | 左树 + 右侧标签页 + 右侧就地表单 | 左树 + 右侧标签页 | 左树 + 右侧标签页 |
| **C 顶栏导航** | 顶部导航 | 顶栏全局切换器 | 全宽列表 + 部门下拉 + 居中弹窗 | 组织页签（部门树 / 岗位列表） | 树形表格 + 详情弹窗 |

三个方案都覆盖：多公司切换、部门/成本中心多级、岗位公司级档案、员工状态机、删除引用阻止、成环校验、停用实体、未分配视图、加载/空/错误状态、窄屏适配。

## 建议重点体验

1. **A 员工页**：点击左侧部门 → 表格联动；新增员工 → 右侧抽屉；编辑 → 抽屉；离职 → 状态与离职日期。
2. **A 部门页**：删除「生产部」→ 引用阻止弹窗；编辑部门 → 上级部门下拉中自身/下级不可选。
3. **状态开关**：公司、部门、岗位、成本中心的启用 / 停用使用滑块；有下级或在职/试用期员工引用时，停用会被阻止并显示原因。
4. **A 成本中心**：选中「未分配」→ 员工列表；删除「生产成本中心」→ 引用阻止。
5. **A 公司页**：切换公司 → 其余页面数据范围变化；「荣新建设」无组织数据，可体验删除确认。
6. **B**：左树 + 右侧标签页；员工表单在右侧就地展开；管理公司弹窗。
7. **C**：全宽员工列表 + 部门下拉；组织页签；成本中心树形表格 + 详情弹窗。
8. 底部「状态」切换加载 / 空 / 错误；「页面流程」「需求差异」。
9. 窄屏：侧边栏折叠、两栏堆叠、表格横向滚动、底部控制条横向滚动。

## 讨论问题

1. 整体导航：A / B / C / 混合？
2. 公司上下文：顶栏全局切换（A/C）还是工作台内选择（B）？公司档案独立页（A/C）还是弹窗（B）？
3. 员工页：常驻部门树（A/B）还是部门下拉（C）？表单：右侧抽屉（A）、右侧就地（B）、居中弹窗（C）？
4. 部门与岗位：五个独立模块（A）、组织页签（C）、单工作台标签（B）？成本中心：左树 + 右详情（A/B）还是树形表格（C）？
5. 哪些交互要保留 / 修改：阻止删除弹窗、成环校验、停用实体显示、未分配视图、加载/空/错误、窄屏。

## 与需求文档的差异

原型内「需求差异」有完整列表。核心边界：多公司但公司扁平；部门任意多级；岗位不绑定薪酬/计算方案/工作日参数；员工 UUID v7 + 工号双标识；不做调岗历史、再入职、RBAC、Excel 导入、考勤、薪酬、账号角色与员工端 H5；成本中心预算只录入，不做统计与预警。
