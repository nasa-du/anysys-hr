荣新员工管理与工资计算系统 · 功能原型（方案化重构）

双组织架构：行政架构（公司-部门，驱动人员 / 岗位 / 权限 / 工资计算）与成本架构（公司-成本中心，独立维护，仅用于工资支出统计与预警） · 岗位档案（公司属性）装配薪酬构成、计算方案与工作日/考勤参数 · 三者彼此解耦、分别复用 · 人员按部门过滤且只选岗位（自动带出三项配置）· 考勤管理（班次/排班表/打卡明细/OA申请，支持跨天与一天多班） · 基于角色的访问权限控制（RBAC） · 员工端 H5（考勤结果 / 工资条自助查询，发布制：后台发布后手机端才可见）

行政架构（公司 → 部门）

维护公司、部门层级（树状）、负责人、成本中心。每个部门归属某家公司，员工通过「所属部门」归属，并据此自动套用其岗位档案（薪酬构成 / 计算方案 / 工作日参数）。支持新增 / 编辑 / 删除（含子部门或仍有员工的部门不可删）。

公司 / 部门层级

部门人数与负责人

部门所属公司负责人在职人数操作
设计要点（双组织架构）：系统并行维护两套组织维度——行政架构（公司 → 部门）与成本架构（公司 → 成本中心），彼此独立、分别维护。人员在两套架构下分别归属（人员管理中单独设置）：行政归属决定岗位适用、权限范围与工资计算等全部既有逻辑；成本归属只决定工资支出统计到哪个成本中心。成本架构不影响任何既有计算与权限逻辑，用于从另一维度统计整个部门 / 成本中心的工资支出，并通过「月度工资预算 + 预警线」为后续工资预警做铺垫。

成本架构（公司 → 成本中心）

独立的第二组织维度：维护成本中心层级、负责人、月度工资预算与预警线。支持新增 / 编辑 / 删除（含子成本中心或仍有员工的成本中心不可删）。

成本中心层级

成本中心与预算

成本中心所属公司负责人人数（含下级）月度预算预警线操作

工资支出统计（按成本架构）

按成本中心归集当月工资支出（应发 / 社保 / 个税 / 实发），与月度预算对比给出预警状态；各级金额含其下所有子成本中心。点击任意行可下钻查看该成本中心的人员明细。

提示：成本架构仅用于统计报表与工资预警，不参与工资计算、岗位适用与权限判定；未设置成本归属的人员汇总在「未分配」行，请到「人员管理」补设。

人员管理

员工全生命周期维护：新增 / 编辑 / 调岗 / 离职，关联所属部门与岗位（岗位自动带出薪酬构成 / 计算方案 / 工作日参数），并单独设置成本架构归属（仅用于工资支出统计与预警，不影响计算）。点击左侧部门树可快速过滤人员。

工资列表

按「员工所属岗位 → 岗位装配的薪酬构成（各项标准金额）+ 计算方案（独立公式）+ 工作日/考勤参数 + 当月导入数据」自动计算；出勤与加班可由「考勤管理」自动算出后回填；字段与公式可在「字段/公式配置」中按计算方案调整

提示：点击任意一行可查看该员工全部字段的计算明细（含其所属计算方案的字段公式）。

设计要点（解耦）：「计算方案」仅承载字段计算公式集，与「薪酬构成」（各项标准金额）、「工作日/考勤参数」（工时与加班倍数等）三者彼此独立、分别复用。计算方案可跨岗位、跨构成、跨工时复用——当多个岗位「工资构成不同、但计算方式相同」时，只需共用同一计算方案，避免重复建方案。

计算方案（公式集）

仅字段计算公式，可复用于多个岗位

方案明细：字段公式

选中方案后可查看其字段公式；点击「配置计算字段」进入该方案的字段公式设置。工作日 / 考勤参数已独立为「工作日/考勤」构件。

设计要点（解耦）：薪酬构成即「薪酬包各项标准金额」（基本工资、高温补贴、加班费、保密津贴、社保/竞业补贴、合计）。岗位可单独绑定某套构成，与计算方案彼此独立，分别复用。

薪酬构成

各项标准金额，可复用于多个岗位（含派生项绩效、合计校验）

设计要点（解耦）：工作日 / 考勤参数（计薪天数、日工时、加班倍数、最低工资）作为独立可复用构件，与薪酬构成、计算方案三者彼此独立。岗位可单独绑定某套工作日参数，按公司/岗位差异设定（如生产类 8h、行政类 7.5h），并可与不同薪酬构成、计算方案任意组合。

工作日 / 考勤参数

工时与考勤相关参数集，可复用于多个岗位（公式中以 {'参数名'} 引用）

参数集明细：具体参数

选中参数集后可编辑其工作日 / 考勤参数，修改后自动触发引用该参数集的岗位重算。

设计要点：岗位档案是「薪酬构成 + 计算方案 + 工作日/考勤参数」的装配点，且带有公司属性。员工在人员管理页只需绑定一个岗位（直接引用岗位档案数据），即同时获得该岗位的三项配置——无需按人设置薪酬方案，也无需在人员页逐一绑定构成/方案/参数。当多个岗位「构成不同、但计算方式或工时相同」时，可共用同一计算方案或工作日参数，显著减少重复配置。

岗位档案

岗位归属某家公司，并分别绑定「薪酬构成」「计算方案」「工作日/考勤参数」。点击岗位可展开使用该岗位的人员。

设计要点：考勤管理由「班次定义 → 排班表 → 打卡明细 / OA 申请 → 考勤结果」四步构成。班次支持跨天（如夜班 22:00–06:00）与同一天多个班次（如早班 06:00–14:00、中班 14:00–22:00），并可设置午休段（产生 4 次打卡）。排班表按自然月维护，支持复制到下一月（自动处理大小月天数差异）。考勤结果由打卡明细 + 排班表 + OA 申请（外出/出差、加班单、请假/补休，仅审批通过）联合计算，直接回填工资列表的出勤与加班字段。

1. 班次定义

定义可复用的班次：起止时间、是否跨天、午休段、休息扣除。结束时间早于开始时间即视为跨天班次（结束时间落在次日）。

2. 排班表

按月维护「谁在哪天上什么班」。点击日期格可增删该天的班次（支持一天多班）。

3. 打卡明细导入

支持钉钉考勤原始记录格式（姓名/部门/工号/考勤日期/考勤时间/打卡时间/打卡结果…）。系统自动过滤「打卡无效」「已被更新」等重复记录，保留「补卡审批通过」「外勤」等有效记录。

4. OA 申请导入（外出/出差 · 加班单 · 请假/补休）

OA 审批通过的申请计入考勤计算；按列名映射，未匹配员工与非「审批通过」记录自动跳过并计数。重新「解析并计入」为覆盖式刷新。

计入规则（仅「审批通过」且姓名匹配员工档案的记录生效）： ① 外出/出差覆盖的排班日计出勤（当日无打卡也计，有打卡按打卡计算工时）； ② 加班单当日加班工时取「打卡计算值」与「OA 审批值」的较大者，审批值按起止时间计算、单日跨度 8 小时封顶、跨天申请按日拆分； ③ 事假不计出勤；带薪假不计出勤但计入带薪假天数（回填后走带薪假工资公式）； ④ 补休/调休的休息日不计出勤，并按「补休天数 × 8 小时」抵扣被补休加班日的加班工时。

5. 考勤计算结果

由打卡明细、排班表与 OA 申请联合计算；结果可一键回填到「月度导入」的出勤与加班字段。

6. 发布到员工端（手机 H5）

员工通过手机端 H5 页面查看考勤结果与工资条。点击「发布」后，系统把当前核算结果做成快照，员工端只能读取已发布快照——计算过程中的中间结果、未发布月份的数据员工一律看不到。

7. 考勤计算规则

控制迟到/早退判定、加班起算与打卡归属窗口。修改后自动重算。

8. 法定节假日清单

清单内的日期按节假日计加班倍数（×3），周末按休息日（×2）。

月度导入只承载当月变动数据（出勤、加班小时、加减扣项）；薪酬项标准、工作日参数等来自岗位档案（薪酬构成 / 计算方案 / 工作日参数）。出勤与加班也可由「考勤管理」按打卡明细 + 排班表 + OA 申请自动算出一键回填，无需手工填报。

字段映射规则（导入列 → 系统字段）

导入时按此映射写入；未映射列自动忽略

面向最终用户开放：业务/财务人员可自行增、删、改、查字段与计算公式，无需管理员改代码。字段名称全系统统一，每套计算方案可定义独立计算公式；编辑时提供字段/函数/参数快捷插入与实时试算，保存前自动校验语法与循环引用。

字段与公式定义（按计算方案）

计算方式：构成（取薪酬构成标准）/ 导入（取月度导入值）/ 公式（按公式计算）/ 固定值。字段名称全系统统一，公式按计算方案独立。

引擎求值顺序（依赖拓扑排序结果）

引擎自动解析公式中的字段引用，构建依赖图并排序；若存在循环引用会在此提示

参数分层管理：工作日 / 考勤参数（计薪天数、日工时、加班倍数、最低工资）已独立为「工作日/考勤」构件，由岗位单独绑定；此处仅维护个税起征点、税率、社保费率等法定全局参数。

全局参数（个税 / 社保 / 保密津贴）

公式中用 {参数名} 引用；修改后自动触发全量重算。这些参数为法定口径，全公司统一。

账号管理

系统用户的创建、编辑、删除与查询；通过为用户分配角色，获得对应的功能模块权限与部门数据可见范围。

角色管理

角色决定可访问的功能模块与可查看的部门范围；为用户分配角色即获得对应权限。修改角色会即时影响所有拥有该角色的用户。

权限生效说明：用户仅能访问其角色所授权模块与部门范围内的数据；工资列表、人员管理、工资导入均按此范围精确过滤（越权数据不可见、越权导入会被拦截）。
